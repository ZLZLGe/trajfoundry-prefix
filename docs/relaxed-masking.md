# 脱敏占位符宽松评估

`scripts/submit_mask_evaluation.py` 对完整标准化日期分区进行单独的宽松比较。它只读 S3、输出共享目录，不改变默认比较策略，也不发布轨迹。

识别 `<大写标签>`、`[大写标签]`（2–64 个字母、数字或下划线，首字符为大写字母），以及大小写不敏感的 MASKED、REDACTED、SENSITIVE 及其下划线后缀。真实 raw/masked-raw 配对证明 PACK_PATH、SCHEMA_PATH、KEY、PATH 可以是原文模板，本模式将这四种标签按字面比较。普通星号不是占位符。

任一侧的占位符允许匹配另一侧 1–256 个非换行字符，不要求实体类型相同。其余文字必须相同；字符串内按一个方向解释全部标记，再检查反方向。两个方向均无法解释的交错脱敏继续保留。这是用户允许误差的局部通配规则，不能证明原文相同。

仅放宽根 messages 的 content 和 tool_calls.function.arguments 内的字符串值。参数对象的键、数组结构、数字／布尔值、工具名称、角色、调用顺序、调用结果引用以及其他消息字段均保持比较。已有 messages_only 身份分组、准入条件、工具 ID 更名及 reasoning 比较口径保持一致。输出不增加轨迹字段。

## 完整候选与最终代表

输入文件必须完整覆盖固定 manifest，并逐条验证字节数和 SHA256。候选按身份和前两条消息的结构分组；结构移除可通配的字符串值，保留其余字段。因此第一条消息就有脱敏差异的配对也能进入比较。组内枚举至少一侧含标记的配对，并用完整消息结构和无标记消息哈希做必要条件过滤，不限邻居或抽样数量。

按比较消息数降序、标记数升序、原文件字节数降序、文件引用升序选择代表。每次删除只允许直接匹配一个最终保留文件。不会把 A 匹配 B、B 匹配 C 推导为 A 匹配 C。

运行基线应为已独立核验且同规则复跑无新增合并的保留集。纯字面前缀不是本模式的新增关系；若新增删除审计发现无需占位符也能合并，会报错。

## 核验与输出

- 全量标记和模板盘点、模型数量、隔离原因。
- 每个候选的匹配结果，以及只有放宽 256 字符限制才匹配的情况。
- 每条输入的去留和最终保留引用；独立原始 JSON 比较器用另一套动态规划核验全部新增删除。
- 全量重读保留文件并重跑宽松比较，要求新增匹配为零；结束时再次核验源 manifest。
- `report.json`、`census.json`、`decisions/`、`audit/`、`retained-input/`、`example-references.json`、`SUCCEEDED`。

业务计算使用 Spark Cluster。纯合成测试检查独立比较器差分、长度边界、全序列差异、身份边界、工具绑定和非传递匹配。真实内容及来源摘录只放仓库外。
