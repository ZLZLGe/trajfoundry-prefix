## 本次只改变什么

两组都独立读取 2026-10-10 的所有标准化轨迹，使用完全相同的输入清单、代码快照和五条消息鲁棒规则。基线为 `extra_information=tools_only`，实验为 `messages_only`：顶层工具定义及其他附加信息都不阻止前缀合并。

仍按渠道、模型、harness、用户和 session 分组；无 session 按日期。messages 中的角色、正文、工具调用名称、参数、调用顺序与工具结果继续比较，工具调用 ID 一致更名仍保持引用绑定。沿用原规则对回放 reasoning 的处理。身份脱敏、匿名历史不足、工具引用异常的隔离规则也保持一致。它是完整消息序列的前缀比较，不是只比较 content 字符串。

原五条规则为：动态首行 cch、assistant 末尾 ASCII 空白、工具调用 ID 一致更名、回放省略完全空 assistant、Claude 身份首段之后的 cch。原始 JSON 及其字段均不改写。默认值仍为 `tools_only`，通过显式参数测试新模式。

本次输入来自 `boyue-rich/normalized/v001`、`deep-infra/normalized/v002`、`free-router/normalized/v006`、`token-plan/normalized/v009` 的 `dt=2026-10-10/`，包括 accepted 与 quarantined，排除来源索引 `lineage.jsonl`。本轮四个渠道该日期均有数据。SXF 只有 2026-08-21，TrustCyberData 为无日期归档。

原 10 月 10–12 日联合测试允许真实 session 跨日期比较，因此此次重新运行单日基线，没有直接拿旧报告的 10 月 10 日小计相减。输入冻结清单哈希：`c193d375065d5505da0dcec785f79fe41c66fcc3230f527a06a1733adfddaa81`。

## 新增加的合并与代表选择

逐条核对全部 6,499,393 项决策：原来保留、现在合并 **23,661 条**；原来合并、现在作为保留代表 **18 条**。两者相减才是净多合并的 23,643 条。放宽工具定义约束后，相同消息的代表选择可能改变，因此不能只数前一项。
