这是在已发布 SXF v004 的 `messages_only`、toolcallid 一致更名等规则之上，单独放宽脱敏占位符后的结果。全部输入来自：

`s3://agent-trajectory/lakehouse/SXF/mul-agent-sxf/normalized/v004/dt=2026-08-21/`

本次仅输出去留清单、统计和证据，未发布 S3 新版本，也未更新指标筛选集。S3 v004 仍为 90,589 条。

## 这次具体找到了什么

| 新增合并依赖的脱敏标记 | 实际删除轨迹数 |
| --- | ---: |
| `[USER]` | 349 |
| `[INTERNAL_NAME_REDACTED]` | 9 |
| 合计 | 358 |

349 条主要是用户名出现在 Windows、Linux 或 macOS 路径中，一份 assistant 正文或工具参数保留原用户名，后续回放变成 `[USER]`。另外 9 条涉及内部名称，一份保留原名称，另一份变成 `[INTERNAL_NAME_REDACTED]`，包含正文和工具参数中的 `.vue` 文件名等内容。

这 358 条中，有有效 session 的 1 条，无有效 session 的 357 条。无 session 的记录仍受原有用户、模型、harness、日期及历史长度保护约束，没有跨过身份分组。

此前 SXF 的脱敏诊断为 0，不能代表没有此类差异：旧探针只识别有限的尖括号标签，没有识别本次实际起作用的方括号 `[USER]`、`[INTERNAL_NAME_REDACTED]`，同时旧索引还存在近邻和开头消息限制。本次候选检查补齐了这些范围。

## 脱敏规则及真实目录调研

实际读取了 TokenPlan、FreeRouter、Boyue 的 `masked-raw/v002` 样本，以及 DeepInfra 的一个小 Parquet 样本。TokenPlan 和 Boyue 的对应 `raw/v001` 已逐字段对照；FreeRouter 同路径的 raw 前缀未找到，不将其样本声明为已确认脱敏前后配对。

真实配对确认 `<SENSITIVE>`、`<PHONE>`、`<IP_ADDRESS>` 等会由脱敏引入；但 `<PACK_PATH>`、`<SCHEMA_PATH>`、`<KEY>`、`<PATH>` 在所查 Boyue 原文中已经存在。因此当前规则采用通用标记识别，同时把这四种模板标记按字面比较，而非继续追加一个穷举式标签白名单。

SXF 没有独立 `masked-raw` 子目录，来源是 `guixu-data/260821/`。对其原始采集的有界样本检查发现，路径内 `[USER]`、`[TMP]` 和内部名称标记在这一层就已存在。可访问源不是脱敏前原文，不能宣称每个占位符的原始值已被还原。

比较模式为 `placeholder-relaxed-v1`：

- 支持 `<大写标签>`、`[大写标签]`，及 MASKED、REDACTED、SENSITIVE 的大小写变体。普通星号不作占位符。
- 占位符可匹配 1–256 个非换行字符，标签名可以不同。仅放宽消息 content 和工具 arguments 内的字符串值；其余正文、角色、工具名、参数结构和调用／结果绑定继续比较。
- 保持原身份分组、toolcallid 鲁棒规则和消息前缀检查。每条删除直接对应最终保留文件，不通过 A→B→C 连锁推导。
- 按比较消息数降序、标记数升序、原文件大小降序、文件引用升序选择代表。原轨迹内容、字段及文件名均不改写。

泛化扫描覆盖 60,959 条含候选标记的轨迹，不能把它们全部叫作“脱敏轨迹”：其中还包括 `[INFO]`、`[P2]`、`[KNOWN]` 等日志、优先级或正文模板。对每条实际删除做逐标签关闭验证后确认，**全部 358 条仅允许 `[USER]`、`[INTERNAL_NAME_REDACTED]` 就仍然成立，不依赖这些普通标记的通配**。

## 核验结果与边界

- 全量输入 90,589 个文件逐条校验大小、SHA256，并核对与此前零新增合并的保留集完全一致。
- 全量必要条件筛选产生 52,555 对候选；完整比较通过 2,375 对。按直接保留代表确定实际删除 358 条，关系对数不能当作删除数。
- 358 条最终删除全部通过另一套原始 JSON 比较器和独立字符串动态规划核验。消息存在其他实质差异、身份不同或工具绑定不同的记录不会因此删除。
- 全量重新读取 90,231 个保留文件，第二遍对 49,529 对候选进行完整比较，新增合并为 **0**。
- 没有检出仅因 256 字符上限而未通过的候选；结束时源 manifest 哈希不变。
- 全部业务比较和归因任务均运行在 `root.datacenter.pjcc.agent_trajectory`，16 个 Executor × 8 核、512 分区，实际 Driver 均成功退出。主任务约 9.14 分钟。

这是用户允许误差的宽松匹配结果，不是所有脱敏前原文都已证明相同。单个字符串按一侧的标记解释另一侧文字，再检查反方向；两边交错脱敏而两个方向均不能解释、占位符跨行或超过边界的情况继续保留。第二遍为零表示本次明确规则下结果稳定，不代表任何语义重复都不存在。
